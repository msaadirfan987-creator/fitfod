# FitnessXpod / FitPod starter

This folder wraps the supplied homepage and experts directory pages in a runnable Next.js app.

## Run locally
1. Install Node.js LTS if it is not already installed: https://nodejs.org/
2. Open this folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open http://localhost:3000

Experts directory: http://localhost:3000/experts

The source ZIP originally contained four page/style files only; the package/config files in this starter were added to make those pages runnable. This is a development preview, not a complete production platform.
